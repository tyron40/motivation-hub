## ⚠️ Troubleshooting

### If Build Fails:
1. Check build logs in Expo dashboard
2. Verify all dependencies are correct
3. Check for syntax errors
4. Retry with `--clear-cache` flag

### If Submission Fails:
1. Verify Apple Team ID is correct
2. Check App Store Connect credentials
3. Ensure build number is unique
4. Review submission logs

### If Ads Don't Show:
1. Verify website added to App Store Connect
2. Check AdMob verification status
3. Wait full 24 hours for verification
4. Verify ad unit IDs match code
